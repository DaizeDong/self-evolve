# Mutation grader contract

`tools.sie.verifiable.mutation_validity_gate` checks whether a Boolean grader detects injected source mutations.

The baseline must return a truthy verdict. A false baseline or an ordinary baseline exception, including `subprocess.TimeoutExpired`, returns the existing invalid result with zero killed mutants, zero total mutants and no survivors. A baseline `BaseException`, such as `KeyboardInterrupt`, propagates.

For each mutant, a returned `False` counts as killed and a returned `True` counts as survived. A grader exception or timeout aborts the gate. The existing `finally` block attempts to restore the original source bytes. After successful restoration, the same grading exception propagates and no partial verdict or kill credit is returned. If restoration itself raises while handling the grading exception, the restoration error propagates with the grading exception as its context; restored bytes cannot be promised. A grading failure cannot satisfy `min_kill_ratio=0`. `BaseException` propagation is unchanged.

When every grading call completes, the result keeps its existing five fields: `valid`, `killed`, `total`, `kill_ratio` and `survivors`. Validity requires at least one mutant and a kill ratio at or above the requested threshold. A zero threshold still permits completed runs with surviving mutants.

The source parser view and byte restoration are separate. UTF-8 decoding and universal-newline normalization determine which mutations are generated; restoration of the original byte sequence is attempted after each mutant. Only successful restoration guarantees the original bytes. Existing behavior for UTF-8 BOM input, invalid UTF-8 and mutant-write failures is unchanged.

Regression sources are generated by `tools/make_fixtures.py`. `byte_preservation_test_source` covers source layouts and restoration paths. `mutation_grader_failure_test_source` covers error identity, timeouts, zero thresholds, failures after earlier verdicts, baseline refusal, Boolean counts and `BaseException` propagation.
